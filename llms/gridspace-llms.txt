# Guava (formerly Gridspace)

> Guava is a voice AI platform for regulated industries (healthcare, banking, insurance, BPOs, government), founded 2013 as Gridspace. It provides an end-to-end conversational voice stack (ASR, LLM, TTS + compliance guardrails) via Python/TypeScript/Elixir SDKs, a `guava` CLI, a managed cloud deploy platform, and a REST API for conversations, transcripts, recordings, and SMS over inbound/outbound WebRTC and SIP. gridspace.com now redirects to goguava.ai.

## APIs

- [Guava Voice Agent REST API](https://goguava.ai/docs/api-overview): Manage conversations, transcripts, recordings, and SMS. Base URL https://api.goguava.ai/v1, bearer API-key auth.

## Specs

- [OpenAPI 3.1](https://raw.githubusercontent.com/api-evangelist/gridspace/refs/heads/main/openapi/gridspace-guava-openapi.yml): 8 operations across Conversations, Messages, and SDK.
